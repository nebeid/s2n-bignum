**2. It's functionally a no-op — only the prologue offsets change, the **body bytes are byte-identical** and total size is unchanged — but it lets the band theorems state a clean `C_ARGUMENTS` body core. We'd then wrap that core with `ARM_ADD_RETURN_STACK_TAC` to prove the prologue/epilogue and produce a whole-function `..._SUBROUTINE_CORRECT` theorem at pc+0, exactly the XTS pattern ([`AES_XTS_ENCRYPT_SUBROUTINE_CORRECT`](https://github.com/nebeid/s2n-bignum/blob/bb2e2585d1ad80375fd06b09251bc52149ebef9e/arm/proofs/aes_xts_encrypt.ml#L5563)).
